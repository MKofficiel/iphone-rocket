# Code of Conduct / Code de conduite

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Be kind, assume good intent, and help people who are stuck: many users here are not developers and are worried about their photos.

Ce projet suit le [Contributor Covenant 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/). Sois bienveillant, présume la bonne foi et aide les gens qui bloquent : beaucoup d'utilisateurs ne sont pas développeurs et s'inquiètent pour leurs photos.

To report a problem, use GitHub's "Report abuse" link, or open a private security advisory if it is sensitive.

Pour signaler un problème, utilise le lien « Report abuse » de GitHub, ou ouvre un avis de sécurité privé si le sujet est sensible.
